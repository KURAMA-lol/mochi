Picking an image converts it to pixel art in the frame you are editing. Fix it by hand below.
JavaScript only, never HTML. Write function(ctx,t,x,y){...}. Buffer is 128×128. ctx.px(x,y,color) = 3×3 block, ctx.r(x,y,w,h,color) = raw rect, ctx.art / ctx.drawArt(x,y,scale) = your ART tab drawing. Code with createFrame runs in ACT mode and must return {frame, fx}.
Paste pixelfx code (a function, a module with createCompanion / createAct / arrowShot.act, or an ACT script). import lines are removed and export is handled for you.
Full animation code (same format). t loops every Loop seconds; use the slider to scrub.
