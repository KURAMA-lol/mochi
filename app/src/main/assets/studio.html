Pixel Studio

Converts the picture to pixel art into the frame you are editing. Then fix it by hand below.
Paste function(ctx,t,x,y){...}. t = seconds, x,y = pointer position in pixels, ctx.art = your grid drawing, helpers ctx.px(x,y,color) and ctx.r(x,y,w,h,color). A full module with createCompanion() (like Lumi) works too.
Save keeps it in your library and downloads name.js — put it in src/fx/custom/.
Full animation code. Same format as the Code tab; t loops every Loop seconds. Use the slider to scrub.
